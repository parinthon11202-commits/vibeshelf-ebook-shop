# Manual Test Checklist

- [ ] หน้าร้านแสดงหนังสือ 3 เล่ม พร้อมปก ชื่อ คำอธิบาย และราคา
- [ ] หน้าร้านไม่เกิด horizontal scroll ที่ความกว้าง 375 px
- [ ] ทุกปุ่มและข้อความสำคัญอ่านได้เมื่อ Zoom 200%
- [ ] เปิดรายละเอียดหนังสือแต่ละเล่มได้
- [ ] Checkout แสดง error เมื่อชื่อว่างหรืออีเมลไม่ถูกต้อง
- [ ] Checkout ที่ข้อมูลถูกต้องสร้างเลข `VIBE-YYMMDD-XXXX`
- [ ] คำสั่งซื้อใหม่มีสถานะ `PENDING`
- [ ] หน้า Mock Payment มี `DEMO ONLY` และไม่มีข้อมูลรับเงินจริง
- [ ] ปุ่มจำลองชำระเงินเปลี่ยนสถานะเป็น `PAID`
- [ ] หน้าสำเร็จแสดงผลส่งอีเมลจำลองและเวลาหมดอายุ 15 นาที
- [ ] ดาวน์โหลด E-book ได้เมื่อสถานะ `PAID` และลิงก์ยังไม่หมดอายุ
- [ ] Tracking ไม่แสดงข้อมูลเมื่อเลขคำสั่งซื้อหรืออีเมลไม่ตรง
- [ ] Tracking แสดงข้อมูลเมื่อข้อมูลทั้งสองช่องตรงกัน
- [ ] ปุ่มขอลิงก์ใหม่ทำงานสำหรับคำสั่งซื้อ `PAID`
- [ ] เมนู Mobile เปิด ปิด และเปลี่ยนหน้าได้
